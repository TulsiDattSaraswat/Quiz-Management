Learn how to structure your quiz files for import

JSON Format Structure

JSON files must contain an array of quiz objects. Here's an example:

[
  {
    "id": 1629000000000,
    "title": "Math Basics",
    "description": "Test your math knowledge",
    "createdAt": "8/16/2026",
    "questions": [
      {
        "text": "What is 2 + 2?",
        "options": [
          "3",
          "4",
          "5",
          "6"
        ],
        "correctAnswer": 1
      },
      {
        "text": "What is 5 × 3?",
        "options": [
          "10",
          "15",
          "20",
          "25"
        ],
        "correctAnswer": 1
      }
    ]
  }
]

📌 Important Rules:

  • id: Unique number (use timestamp or any large number)
  • title: Quiz name (required, string)
  • description: Optional quiz description
  • createdAt: Creation date (format: M/D/YYYY)
  • questions: Array of question objects
  • text: Question text (required)
  • options: Array of answer options (minimum 2)
  • correctAnswer: Index of correct option (0-based, so 0 = first option, 1 = second, etc.)

✅ Example Breakdown:

In the example above:

  • First question "What is 2 + 2?" has 4 options
  • The correct answer is at index 1 (which is "4")
  • Second question correct answer is also index 1 (which is "15")

Excel Format Structure

Each quiz should be in a separate sheet. Here's the column layout:

Row Column A Column B Purpose
1 Quiz Title: My Quiz Name Header
2 Description: Quiz description text Header
3 Created: 8/16/2026 Header
4 Empty row Separator
5 Question # Question Text Option 1, 2, 3, 4... | Correct Answer
6+ 1, 2, 3... Your question text Option text | Correct option text

📋 Excel Sheet Example:

Quiz Title:    | General Knowledge
Description:   | Test your knowledge
Created:       | 8/16/2026
               |
Question #     | Question Text              | Option 1    | Option 2 | Option 3    | Option 4   | Correct Answer
1              | What is the capital of...  | London      | Paris    | Berlin      | Madrid     | Paris
2              | Which planet is largest?   | Jupiter     | Saturn   | Neptune     | Venus      | Jupiter
3              | Who wrote Romeo & Juliet?  | Shakespeare | Marlowe  | Jonson      | Fletcher   | Shakespeare

📌 Excel Format Rules:

  • Row 1: "Quiz Title:" in A1, your title in B1
  • Row 2: "Description:" in A2, description in B2
  • Row 3: "Created:" in A3, date in B3
  • Row 4: Leave empty (separator)
  • Row 5: Column headers (starts with "Question #")
  • Row 6+: Your questions and options
  • Options: Columns C onwards (up to 10+ options per question)
  • Correct Answer: Last column - must match one of the option texts exactly
  • Sheet Name: Will be used as quiz title if not specified in header
